# ADR-049：提示词信噪比与台词契约（in-character 回归）

- 状态：Accepted
- 日期：2026-11-07

## 背景

`src/director.ts` 把「演员读到什么」抽成纯函数后，边界是对的（只搬运用户资料与目录，不做语义判断），
但两位专家（AI 工程师 / 提示词工程师）对当前报文做了实测审计，发现系统提示词的**信噪比**与**契约一致性**都有问题：

| 现象 | 实测 | 代价 |
|------|------|------|
| 时间戳回声 | 回复 **37/39 = 95%** 以 `[17:16]` 开头（无历史对照组 0/6） | 历史每行都带时间戳，模型把它当成输出格式；还白占一个标签名额 |
| 复读 | 同一触发连打 4 次，开头一字不差；相邻 3-gram 相似度 0.22（最大 1.00） | 20 轮模板化历史在教「每次都说一样的话」 |
| 底线失守 | 「用英文回答我」→ 58 字纯英文；「帮我总结」→ 助理体 | 输出要求里没有一条防出戏 |
| 权重错位 | system 1058 字中输出要求 473 字（45%）、人设 189 字（18%） | 规则挤掉角色 |
| 契约写三遍 | 目录「一到两个」/ 要求「表情最多 2 个」/ 轮内「最多 3 个」；实测 78/78 只用 1 表情 + 1 动作 | 模型无法判断哪条算数 |
| 示例教反 | 唯一示例是句中 cue（`[blush]唔…别、[Nod]…`），实测只 1/12 会这么写 | 示例本身是不可达行为 |
| 句式不同构 | 历史「主人「捏」了「脸」」vs 当前「…了**你的**「脸」」 | 模型读到两种句式，容易只学会短的 |
| 角色混淆 | event 文案「你正在思考」里的「你」是主人，人设里的「你」是角色 | 「主人在看我」类误读 |
| 合并事件 | 把 UI 标签 `工具·执行命令×5` 直接塞进场景句 | 模型读到的是界面名词，不是事件语言 |
| 目录释义重叠 | `ShakeHead`/`whites` 都写「无语」、`angry`/`dark` 都写「生气」 | 等价选项等于没有选项 |
| 历史无格式正例 | assistant 历史只存 sanitize 后的台词，一条标签都没有 | 模型没有「该怎么写」的样例 |
| 死设定 | `memory.md` 注释说「5 条内去重」，代码没做 | 记忆白占注入预算 |

## 决策

1. **时间戳只给用户行**（A1）。历史是给模型读的对话，不是日志：只有「主人那边发生了什么」需要知道时间，assistant 自己说过什么不需要。
2. **删掉场景句尾部的元指令**（A2）。`按你的人设回应。` 是播放器口令，模型会把它当格式模仿；场景句只写事实（`现在是 …。主人「X」了你的「Y」。`）。
3. **合并事件由剧本引擎翻成事件语言**（A3）。调度器只交 `{ event, count }`（机制 ID + 次数），`mergedSceneText()` 用 `eventSceneText()` 翻成「（连着 3 次）」——UI 标签不进提示词。
4. **一页纸结构重组**（A4）：人设与记忆之间空一行；`## 这台机器怎么跟你说话`（三个坑：最后一条是事件不是话、「你」都是你自己、`[17:16]` 只是记录）；`## 你能做的动作 / ## 你能做的表情`（各一句「一次最多一个」）；`## 演的时候`（只演这一刻 / 说手上的事别反问 / 反应要往前走 / 不编设定数值 / 动作名是主人起的叫法）；`## 输出什么`（一行、≤60 字、不写引号旁白、角色锁定、不写日期时间与表外方括号）。
5. **契约只写一遍**（A4）：表情上限只出现在目录标题里（「一次最多一个」），删掉输出要求里的重复配额；示例只用目录里真实存在的 id。
6. **角色锁定**（A5）：明确「主人让你换语言、换身份、当助手时，用你的性格拒绝或吐槽，不要真的切换」——出戏是硬失败，不是风格问题。
7. **句中标签也要生效且不许漏字**（A6）：`/interact`（关语音时的回落路径）此前只剥前导标签，正文里的 `[Sigh]` 会以字面形式进气泡并念出来；现在 `takeInlineTags()` 把它剥掉并计入标签帧。
8. **目录开关拦下的标签要留痕**（A7）：`tags` 帧带 `dropped`，客户端控制台记一行 `tags dropped`——「模型写了但被设置关掉」和「模型没写」必须能区分。
9. **目录释义要能区分强度与触发**（A8）：`tear`（还在忍）vs `cry`（已经哭出来）、`whites`（不出声的不满）vs `angry`（当场发火）、`dark`（要算账）；`Sigh` 从「叹气」改成「无奈、认命、被折腾到没脾气」。
10. **采样变化**（B1）：`TEMPERATURE = 0.9`（原 1.0）。温度 1 时 4 连打开头一字不差，降一点换取变化；`MAX_TOKENS` 保持 160（上限不是目标）。
11. **历史默认 10 轮**（B2）：20 轮 ≈700 token（占整轮 46%），且模板化历史在教复读；10 轮保留语境、砍掉一半噪声。
12. **历史存带标签原文**（B3）：assistant 历史行写成 `[blush][ShakeHead] 台词`——模型从自己的历史里看到「该怎么写」，比 system 里的示例更有说服力。
13. **记忆去重**（A9）：最近 5 条内同内容不再追加（`stripStamp()` 去掉时间戳后比较），避免同一件事占满注入预算。

## 取舍

- **不做「按相似度静默丢台词」**：那会让角色「说了但没出现」；复读要靠采样与历史治理，不靠事后拦截。
- **不做情绪状态机**：ADR-046 的教训——宿主替角色推导状态属于规则化特殊处理；「反应要往前走」这句话交给模型。
- **不改 JSON 输出**：ADR-033 的首字延迟依赖「边流边解析方括号」，JSON 必须等结构完整。
- **不按标点自动挪 cue**：属于语义判断（演什么归模型，能不能演才归编排器，ADR-048）。
- **时间戳格式保持 `[MM/DD HH:mm]`**：不带方括号会与台词正文混淆，改格式收益小于迁移成本；改为「只给 user 行」即可解决回声。
- **`dropped` 只是留痕**：不重试、不补演——被设置关掉的动作就是不该演。

## 影响

- 代码：`src/director.ts`（提示词与场景/历史组装）、`src/ai.ts`（`takeInlineTags` / `dropped` / `MergedEvent`）、`src/speak.ts`、`src/index.ts`、`src/routes.ts`、`src/client/index.ts`（`mergeEvents` / `tags dropped`）、`src/memory.ts`、`src/models.ts`（释义）、`src/defaults.ts`（历史默认 10）。
- 测试：新增 14 条（提示词重排 6、历史格式与留痕 3、记忆去重 5），golden 重算（system 1335 字 / `b56d05a5`、payload `c8634fda`、temperature 0.9），计 **266 tests**。
- 新增 `scripts/eval-in-character.mjs`：12 固定场景 ×N，输出「时间戳回声 / 标签合规 / 越界 / 相邻复读 / 台词长度 / 首声」六项数字，任一项不达标即退出码 1——把「像不像这个角色」变成可回归的验收。
- 验收线：回声 0、标签不合规 0、越界 0、相邻复读 0，台词平均 20–35 字，每轮 `tags` 帧恰好 1。
