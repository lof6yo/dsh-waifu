# ADR-024：表情可叠加（互斥组）+ 动作组中文显示名

- 状态：Accepted
- 日期：2026-11-05
- 取代：ADR-023 的「每个槽位最多 1 个表情」与「动作组用英文原名展示」两条

## 背景

ADR-023 把动作组与表情合成一个「动作 / 表情」混选列表，但规定每个槽位最多 1 个动作组 + 1 个表情。
实际用下来有两个问题：

1. **表情并不是全都互斥**：模型里每个表情是独立的 `ParamSwitch*`，「脸红 + 眼泪」「生气 + 高光消失」
   这类叠加本该成立，被「只能选一个」卡掉了。
2. **列表里中英文混排**：动作组显示英文 id（`Idle` / `ShakeHead`），表情显示中文（脸红 / 星星眼），
   同一个下拉里两种语言，选中后的 tag 也是英文，看起来像显示 bug。

## 决策

1. **表情按互斥组收敛**：`ExpressionDef.exclusive` 标记互斥组——
   - `eye`：星星眼 / 白眼 / 泪花 / 爱心眼 / 眼泪（眼睛形态同一时刻只能一种）
   - `skin`：脸红 / 脸黑 / 血（皮肤染色同一时刻只能一种）
   - 无标记（生气、高光消失）：可自由叠加

   同一组内后选的替换先选的；不同组、以及无组的表情可以同时开。
2. **数据结构不变**：`motions: string[]` 依旧混存，`splitMotionSelection()` 返回
   `{ motion, expressions: string[] }`；`normalizeMotionSelection()` 按互斥组裁剪。
3. **运行时合并参数**：`expressionParams(ids)` 把选中的表情参数取并集，`applyExpressionParams`
   仍按 `EXPRESSION_FADE_MS` 淡入淡出，写入并集、其余开关写 0。
4. **动作组补中文名**：`MOTION_LABELS`（Idle→待机、Nod→点头、ShakeHead→摇头、Tilt→歪头、
   Sway→左右晃），`motionLabel()` 未收录时回退原名。下拉项、选中 tag、卡片摘要统一用它。
5. **下拉重开时滚动到已选项**：`ThemeMultiSelect` 打开后把第一个 `aria-selected` 项滚进可视区，
   避免列表总停在顶部、已选项藏在下面（观感像勾错）。

## 后果

- 触摸/事件可以配置「摇头 + 生气 + 脸红」这类组合；同一部位的临时表情也是一组。
- 中英文统一为：列表与 tag 都显示中文，内部仍存英文 id（配置可读、向后兼容）。
- 自定义动作组（非内置）没有中文名，仍显示原名——这是可接受的回退。
