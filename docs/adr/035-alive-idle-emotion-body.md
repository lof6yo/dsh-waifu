# ADR-035 让角色「更活」：待机小动作 + 情绪标签 + 说话身体语言

- 状态：已采纳（2026-11-06）
- 相关：ADR-021（基础动作集）、ADR-024（多表情互斥）、ADR-033（流式语音与口型）

## 背景

角色只在「事件发生 / 被点 / 说话」时有反应，平时是 5 秒循环的 Idle，看起来像定格动画；
AI 台词只有文本，表情/身体跟情绪无关；说话时也只有一个嘴在动。

## 决策

1. **待机小动作轮播**（`Glance` / `Perk` / `Shift` / `Sigh`）
   - 每隔 7–16s 随机播一个，幅度 8–16°（一眼能看出来，但仍属「微动作」），只驱动头部角度与位移。
   - 耳朵、尾巴在 `简.physics3.json` 里 Output Weight 全为 100，动作写它们无效；
     驱动 `ParamAngleX/Y/Z`、`ParamAnglePX/PY` 让物理链自己把耳朵尾巴甩起来。
   - 调度只挂一个 `setTimeout`（无轮询）；非 idle、互动中、页面不可见时延后 4s 重试。
   - 开关 `idleMotionEnabled`（默认开）。

2. **情绪标签**（`[shy] 台词`）
   - 提示词要求模型在开头写一个方括号情绪标签，取值
     `happy / angry / sad / shy / surprised / smug / neutral`（中文别名也认）。
   - Host 侧在流式与非流式两条路径都剥掉标签：标签永远不进气泡、不进 TTS；
     流式时标签没闭合前先攒着，闭合后先发 `emotion` 事件再发文本。
   - 客户端把情绪映射成临时表情（happy→star、angry→angry、sad→tear、shy→blush、
     surprised→whites、smug→heart），保持 4.2s 后回落到事件表情。

3. **说话时的身体语言**
   - 口型张开量（AnalyserNode RMS）顺手带一点点点头（3°）、挑眉（0.12）与眼球下压，
     实现在 `internalModel.update()` **之后**追加写值：只影响本帧渲染，不二次点燃物理。
   - 与「口型跟随」共用开关，音量归零即恢复。

## 后果

- 空闲时不再定格，但每个微动作都会打断 Idle 循环再回 Idle（`motionFinish` → 恢复状态动作）。
- 情绪依赖模型配合；模型不写标签时行为与改造前一致（无表情切换）。
- 说话身体语言是纯视觉叠加，物理不受影响，因此不会出现胸部/头发被反复甩动的怪异感。
