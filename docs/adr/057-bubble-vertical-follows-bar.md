# ADR-057：对白气泡纵向位置并入交互条几何

日期：2026-11-09
状态：已采纳（取代 ADR-056 中「收起后锚点 = 模型包围盒顶端」与「保留 `bubbleOffsetY`」两点）

## 背景

ADR-056 让气泡锚点跟随「交互条顶端 / 模型包围盒顶端」，但仍保留独立的 `bubbleOffsetY`。实际观感有两个问题：

1. 交互条收起后气泡落回模型包围盒顶端，而 Live2D 的包围盒比视觉头顶高出一截，气泡看起来仍悬在半空（用户反馈「交互条消失后气泡并没有下沉到原来交互条的位置」）。
2. 「交互条位置」与「气泡位置」是两套纵向配置，用户要分别调 `barOffset` 与 `bubbleOffsetY` 才能让两者贴合，容易对不上。

用户提出：把两个配置合并成一个——交互条可见时气泡底边与条顶间距固定 10px，交互条不显示时气泡补到交互条原来的位置。

## 决策

- 删除设置项 `bubbleOffsetY`（及 `DEFAULT_BUBBLE_OFFSET_Y` / schema 字段 / 设置页输入框），气泡纵向位置完全由交互条几何推导；水平偏移 `bubbleOffsetX` 保留。
- `barPosition === 'top'` 且交互条可见（未自动收起、`barH > 0`）：
  - 气泡底边 = 交互条顶端 − `BUBBLE_BAR_GAP`（10px）= `bounds.y - barH - 8 - barOffset - 10`。
- 交互条自动收起、或 `barPosition === 'hidden'`：
  - 气泡底边 = 交互条原本的底边槽位 = `bounds.y - 8 - barOffset`（`barH` 抵消，不依赖条是否已测量），气泡补进条原来的位置，不再用模型包围盒顶端。
- `barPosition === 'bottom'`：气泡底边贴模型包围盒顶端 `bounds.y`（条在下方，不参与气泡定位）。
- `barOffset` 成为唯一的纵向控制：调它时交互条与气泡一起移动；不再存在第二套纵向偏移。
- `setBarAutoHidden` 切换时立即重排气泡；调试面板避让、视口顶部 clamp、水平居中逻辑不变。

## 备选方案

### 保留 `bubbleOffsetY`，只把收起态锚点改成条的底边

- Pros：改动小，用户仍可单独调气泡高度。
- Cons：正是用户要合并的两套纵向配置；显示态间距也要用户自己调，且与条高/`barOffset` 耦合。
- Rejected：删除独立偏移，间距固定 10px。

### 拆成「贴条间距」「贴模型间距」两个配置

- Pros：两种状态都能微调。
- Cons：配置项反而变多，违背合并目标；实际使用中用户只想让气泡跟着条走。
- Rejected：只保留一个纵向控制（`barOffset`）。

### 气泡改为相对交互条 DOM 定位

- Pros：不用重算条顶/条底。
- Cons：与 ADR-056 的否决理由相同——交互条可能晚于气泡建立、收起只是 `opacity` 隐藏，DOM 相对定位更难；条在下方时仍要退回模型顶端。
- Rejected：继续用包围盒 + `barOffset` 的纯计算几何。

## 后果

- 交互条可见时气泡稳定悬在条顶上方 10px；收起后气泡落到条原本的底边，不再悬空；重新出现时回到条顶上方。
- 老设置里的 `bubbleOffsetY` 被忽略（文件里残留无害，下次写回时消失）；用户失去单独调气泡高度的能力，改 `barOffset` 时条与气泡一起动。
- `barH` 尚未测量的极短窗口内（首帧）按条的底边槽位兜底，测量完成后切到可见态几何，无可感知跳变。
