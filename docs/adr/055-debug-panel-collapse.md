# ADR-055：调试面板折叠、按视口给足尺寸、控制台自适应高度

日期：2026-11-09
状态：已采纳

## 背景

调试面板（ADR-044）上线后暴露三个使用问题：

1. 标题栏右上角的「↺」只能恢复自动跟随；用户想临时收起面板看看角色时没有入口（面板只能关掉再开）。
2. 默认尺寸窄而矮：自动模式宽度按画布宽度算、上限 280 px，高度上限 420 px 且不超过半屏。控制台又按固定 20 行（320 px）占位，面板稍微一矮，内容区就出现整块滚动条——既挤又难读。
3. 面板上下拖动时对白气泡会跟着跳：气泡避让只看 `debugPanelTopLogical/BottomLogical`，而手动模式每帧也会写这两个值，于是拖动面板就等于拖动气泡锚点。

## 决策

- 标题栏右侧按钮从「↺」改为**折叠/展开**（`▾` / `▸`，带 `aria-expanded` 与 title）。折叠只保留 34 px 标题栏，隐藏内容区与四角把手；展开恢复用户上一轮的尺寸（几何仍在 `debugPanelManual` / localStorage 里）。恢复自动跟随改用**双击标题栏**（手势不变，仍不需要额外按钮）。
- 默认尺寸按视口给足：宽 `clamp(max(320, innerWidth-32), 320, min(460, 视口可容纳宽))`，高 `clamp(max(400, 70% 视口高), 400, min(640, 视口可容纳高))`；手动最小尺寸从 180×140 提到 **320×400**（再小放不下控制台与预览行）。
- 内容区改为纵向 flex：`overflow:hidden`（不再出现面板级滚动条），除控制台外的区块固定高，控制台 section `flex:1 1 auto`、`conBody` `flex:1` 在自身内部滚动。删除固定 20 行的 `CON_VIEW_LINES`，行高 `CON_LINE_HEIGHT=16` 仍用于滚动计算。
- 气泡避让只在**自动跟随**模式下生效：条件加 `!debugPanelManual`；折叠态按 34 px 估算面板底边。手动摆放后气泡始终贴模型，拖面板不再带着气泡跑。

## 备选方案

### 保留「↺」，把折叠放到标题栏另一侧
否决：标题栏本来就窄，两个按钮挤；而且双击恢复自动跟随已经够用。用户明确要求右上角按钮变成折叠。

### 折叠改为关闭面板（等同 `debug` 开关）
否决：折叠是临时查看状态，不该写设置、也不该走 Host 往返；关闭再打开会丢控制台滚动位置与预览状态。

### 面板整体滚动、只把控制台调高
否决：用户明确要取消面板级滚动条；而且面板级滚动会把标题栏/预览区一起滚走，交互更差。

### 气泡继续避让手动摆放的面板
仍否决：手动摆放的面板位置完全由用户控制，任何「自动避让」都会在拖动时造成气泡跳动；遮住就拖开更直观。

## 后果

- 手动摆放后若面板正好盖住气泡，气泡不会自动让开（这是预期行为）；折叠/拖走面板即可。
- 折叠状态不持久化：刷新或关开面板后回到展开态。
- 小视口（<352×416）下面板可能贴近视口边缘，仍由 `clampDebugPanelGeometry` / `debugPanelSizeBounds` 夹在视口内。
- localStorage 键与几何 schema（`dsh-waifu.debug-panel:v1`）不变，老装机升级后沿用原位置；旧记录若小于新最小值，会在应用时被夹到 320×400。
- 调试面板相关的 spec 验收清单与 README 文案同步更新；无新增设置项，`settings.jsonc` 版本不变。
