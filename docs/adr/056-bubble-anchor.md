# ADR-056：对白气泡锚点跟随模型 / 交互条顶端

日期：2026-11-09
状态：已废弃（由 ADR-057 取代）

## 背景

交互条（ADR-034）配合无操作自动隐藏（ADR-053）贴在模型包围盒上方。对白气泡原先固定以模型包围盒顶端为锚点（垂直偏移默认 24px），交互条显示时两者只是靠着偏移量"碰巧"不重叠；交互条 10 秒后收起，气泡仍停在原来的高度，模型与气泡之间就空出一段（用户反馈「隐藏时对话气泡有点高」）。

改偏移量也不对：`bubbleOffsetY` 是相对模型顶端的，没法表达"贴着交互条顶端"；按交互条高度做临时补偿又需要和 `barOffset` 联动，两种状态两套几何，容易对不上。

## 决策

- 气泡垂直锚点改为跟随**当前最上方的那个元素**：
  - 交互条贴在模型上方（`barPosition === 'top'`）且当前可见（未自动收起）时，锚点 = 交互条顶端 = `bounds.y - barHeight - 8 - barOffset`；
  - 其它情况（自动收起、`barPosition` 为 `'bottom'` / `'hidden'`、交互条尚未测量出尺寸）锚点 = 模型包围盒顶端 `bounds.y`。
- 设置项 `bubbleOffsetY` 语义保持不变：锚点之上的向上间距（负值向下），交互条收起/展开时气泡自动随锚点上下移动，不需要用户为两种状态分别调偏移。
- 水平位置、调试面板避让、视口顶部 clamp、最长显示等逻辑不变；ADR-053 里按 `barHeight + 8 + barOffset` 计算"下移量"的临时补丁删除。

## 备选方案

### 保留模型顶端锚点，仅在交互条收起时下移（ADR-053 的补丁）

- Pros：改动最小，`bubbleOffsetY` 的老值语义完全不变。
- Cons：交互条显示时气泡仍按模型顶端算，只是"碰巧"高出交互条；收起时再按交互条高度补偿，两套几何在不同 `barOffset` 下补偿量不同，容易对不上。
- Rejected：直接把锚点切换成"看得见的那个顶端"，只有一套几何。

### 固定间距 8px、忽略 `bubbleOffsetY`

- Pros：实现最简单，气泡永远贴顶。
- Cons：用户失去调气泡高度的能力，对喜欢把气泡放高的用户是倒退。
- Rejected：保留偏移设置，把间距交给用户调。

### 气泡改为相对交互条 DOM 定位

- Pros：不用重算 `barTop`。
- Cons：气泡与交互条生命周期 / 测量时机不同（交互条可能在气泡之后建立，收起时只是 `opacity` 隐藏），DOM 相对定位更难做；且交互条贴在下方时仍要退回模型顶端。
- Rejected：继续用包围盒 + `barOffset` 的纯计算几何。

## 后果

- 交互条收起时气泡自然下落、出现时自然回升，不再悬空。
- ADR-057 起本决策中「收起后锚点 = 模型包围盒顶端」与「保留 `bubbleOffsetY` 偏移」两点被取代：气泡纵向位置并入交互条几何（可见时条顶上方 10px，收起时补到条的底边槽位），`bubbleOffsetY` 设置项删除。
- `bubbleOffsetY` 现在表示"距当前锚点的间距"；老配置里为避开交互条手动调大的值（如 24、36）会比以前显得高，可调到 0–8 左右。
- 交互条贴在下方或设为"不显示"时，锚点行为与旧版一致（模型顶端），不受影响。
- 交互条高度尚未测量（`barH === 0` 的极短窗口）时按模型顶端兜底，下一帧自动切回交互条顶端，无可感知跳变。
