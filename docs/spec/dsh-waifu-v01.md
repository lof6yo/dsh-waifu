# Spec: Live2D 宠物插件（v0.2：内置「简」+ 自定义触摸部位）

用户可感知行为规格。对应 Intent：[`../intent/dsh-waifu.md`](../intent/dsh-waifu.md)。
状态事件与挂载点基于实测（ADR-002）；渲染技术基于 ADR-003；内置模型与自建动作、touchbox 部位见 ADR-014；DSH 0.2.x settings 适配见 ADR-013。

## 1. 概述

DSH Web GUI 中一只悬浮于角落的 Live2D 桌宠，实时镜像当前会话 agent 状态（思考/空闲/出错/完成/交付/等审批），支持**用户自定义触摸部位**（touchbox）互动、任务完成庆祝；台词与动画按**事件**绑定配置（空闲/思考/出错/完成/交付/等审批各配动作组与台词池，去掉了固定人设；后续版本再加入 LLM 人设提示词说话）。内置模型**只有「简」一个**，随插件包分发（动作组只有自建 `Idle`，见 ADR-017），开箱即可用。本版设置页不提供模型选择/导入。默认开启、默认右下角、小尺寸、可隐藏。

## 2. 启用与设置

- 插件启用后宠物默认显示在**右下角**（停靠角固定右下角，不可配置；拖动后可自由放置）
- 设置入口：DSH 设置面板顶层「桌宠配置」tab（`settings.section`）；设置持久化到插件私有 `$DSH_HOME/waifu/settings.jsonc`（JSONC；ADR-013）
- 单页设置流程（从上到下，每个 Section 有统一标题与说明）：**显示 → 事件绑定 → 触摸部位 → 开发者选项**（本版只内置「简」模型，不提供模型选择/导入）。「显示」内含三张带标题的卡片：基础显示（开关/尺寸/渲染帧率）、画布与位置（留白/默认位置/归位）、对白气泡（位置与样式）；采用**显式保存**（无自动保存；切模型/离开设置时自动补存）：事件绑定分组在 `eventsDirty/saving/error` 时显示保存状态行（已保存时间/失败原因）；触摸部位按**部位粒度**：只有被改动的部位卡片顶部显示「● 未保存改动 · 保存」，新建/删除/排序等结构变更在分组顶部提示保存
- 设置项：
  - 开关（显示/隐藏）
  - 尺寸滑杆（40–400px，默认 200）
  - **画布留白**：水平/垂直留白（每侧，占尺寸百分比 0–300，默认 125/50）——角色四周留出的可绘制空间，防止大幅动作/物理甩尾被裁切
  - **默认位置（中心点）**：显示区中心点距窗口右边/底边，**按当前窗口画布（视口）宽/高的百分比**取值（0–100，默认 16/24）——首次启动与「归位」时使用；「归位」由宠物半边按视口与画布尺寸计算中心点位置后 `POST /set-display`（只改位置、尺寸不变）；「归位」按钮位于「中心距下」一行右侧
  - **对白气泡**：位置（相对角色包围盒顶部中心的水平/垂直偏移 px，默认 0/10；垂直偏移**正值向上、负值向下**）、背景色/背景不透明度/文字颜色（默认 #ffffff / 92 / #222222）
  - **渲染帧率**（尺寸下方独立分组，标题「渲染帧率」）：一行三个**自绘圆形单选**（○ 30 / ○ 60 / ○ 不限制帧率；配置值 `maxFps`：`30` / `60` / `0`）；默认 **30**；改档经 SSE **立刻**作用到 PIXI `ticker.maxFPS`，无需重启/刷新
  - **事件绑定**（独立分组，标题「事件绑定」）：6 个事件各配「动作组多选 + 台词池」（思考/等审批为三阶段台词：入态 / 15s / 40s 与 入态 / 30s / 90s）；每张卡可「恢复默认」；改动即时保存并经 SSE 生效
  - **触摸部位**（独立分组，见 §4）：编辑开关 + 部位/box/台词/动作组编辑器 + **当前模型状态动画映射**（6 状态多选，可覆盖内置默认）
  - **开发者选项**（独立分组）：总开关 `developerMode`；开启后显示**调试面板**开关（`debug`）与**显示触摸部位色块**（`showTapZones`；与调试面板可独立开关）
- 调试面板（debug 开启时显示）：实时 agent 状态、宠物当前状态/动画、模型信息、最近气泡、错误日志、FPS；提供「演示状态」切换（强制 空闲/思考/等待/完成/交付/出错）与模型原生动画预览。面板为**绝对定位浮层**，水平居中于角色模型、浮在其上方（空间不足时贴角色顶部），不占布局、不推动画布；调试面板可见时对白气泡再叠在面板上方
- **显示触摸部位色块**（`showTapZones`）：在模型上叠加当前生效的触摸部位 box（部位名标签；pointer-events:none）；与编辑态共用同一套绘制逻辑
- 宠物悬浮菜单（右键或悬浮时出现）：隐藏、设置、切换到空闲/思考演示动画（调试用）

## 3. 状态镜像（核心）

状态机六态，映射到真实 DSH 事件（ADR-002/012）。**台词与动作由用户在设置页「事件绑定」配置**（未配置的沿用内置默认）：

| 宠物状态 | 触发事件 | 表现（动作/表情 + 气泡） |
|----------|----------|--------------------------|
| 空闲 | `agent/status` status=idle（非刚完成） | 待机动画（默认 `Idle`：呼吸/微摆/眨眼）；偶发瞬态气泡（事件 idle 台词池） |
| 思考中 | `agent/status` status=running | 歪头/思考动画（`Thinking`）；气泡**常驻**，文案随思考时长阶段演进 |
| 出错 | `agent/error` | 委屈表情（默认 `Error`）；瞬态气泡（事件 error 台词池） |
| 完成 | `agent/turn-stopping` + running→idle 下降沿 | 欢呼/点头动画（默认 `Done`）；瞬态气泡（事件 done 台词池） |
| 交付 | `session/event` 中 `deliverables/presented` | 交付庆祝（默认与完成同链，可单独映射）；瞬态气泡（事件 delivered 台词池） |
| （可选）等审批 | `approval/request` | 张望动作（默认 `Waiting`）；气泡**常驻**，文案随等待时长阶段演进（三阶段台词池） |

- 状态变化即时反映（事件驱动，SSE 推送）
- **长状态气泡与状态同生命周期**：思考中/等审批期间气泡常驻并按入态后耗时**阶段演进**文案（事件 `thinking`/`waiting` 的 3 组台词池）：思考 入态/约15s/约40s，等审批 入态/约30s/约90s；每次阶段切换重播一次该状态动作；某阶段台词池留空 → 该阶段不显示气泡
- 空闲/出错/完成/交付为短状态：气泡约 2.5s 后自动隐藏
- **事件绑定体系**（ADR-015）：每个事件 = 动作组候选（随机播一个）+ 台词池；内置一套中性中文默认文案；用户可在设置页逐事件覆盖（含长状态三阶段），恢复默认随时可回；不再有固定人设/人设文件（后续版本计划用 LLM 人设提示词接管说话）

## 4. 触摸互动（用户自定义 touchbox）

### 4.1 部位抽象

- 每个部位 = `name`（展示名）+ `boxes[]`（一到多个矩形）+ `motions[]`（触摸时播放的动作组候选）
- 每个 box = `{left, top, right, bottom}`，为**相对模型包围盒**的 0–1 归一化坐标（左上右下）——这是存储/判定格式；设置页输入按**左下角为原点**的百分比展示（上 = box 上边离底边的距离，调大即往上长；下 调小即往下长），越界自动夹到 0–1，左右/上下颠倒自动交换，零面积 box 丢弃；单部位最多 12 个 box
- **图层**：部位列表顺序即图层顺序，**第 0 项为最上层**；设置页可上移/下移调整（保存按该顺序持久化）
- 命中判定：点击点换算到包围盒比例坐标 (nx, ny)；**按图层顺序从上到下遍历**，返回第一个命中任意 box 的部位（box 重叠时上层部位生效）；未命中不响应
- 命中检测不再依赖模型 HitArea，也不再使用旧的「空间回退阈值分档」（spatialTap 已移除）

### 4.2 命中后的表现

- 台词选择：部位配置了**自定义台词**（`part.lines`）→ 从该部位台词池随机选一条（避开同一部位上一条）；**未配置 → 不显示气泡，只播该部位动作**（不再有固定人设台词池兜底）
- 动作：从该部位 `motions` 中随机选一个动作组播放（FORCE 优先级，可打断状态动画与上一次互动；`motionFinish` 后回到当前状态动画）；`motions` 为空则只出气泡
- 点击/拖动判定：按下后移动 ≤ 6px 松手 = 点击（触发互动）；> 6px = 拖动（取消本次互动）
- 防刷屏：点击互动 80ms 防抖；每次有效点击立刻换一条随机台词并重播动作，同一池内避开上一条
- 互动动画可打断当前状态动画与上一次互动；动作期间抑制鼠标跟随，播完后恢复
- 拖动：实时跟随指针，拖拽中暂停气泡与触摸互动；松手后停留并持久化位置（right/bottom）；可拖到窗口任意位置、允许一半移出窗口，但**宠物画布中心点始终被约束在视口内**（不会拖丢）
- **点击穿透**：宠物画布/容器的透明区域 `pointer-events: none`，点击直接落到下层 DSH UI；只有当前触摸部位的 box 范围（以及无部位时模型包围盒）接收点击/拖动，不会用一张大画布挡住界面
- 鼠标跟随（默认开启，无设置项）：鼠标在页面任意位置移动时，头/眼睛/身体平滑看向鼠标；拖拽中/页面失焦/宠物隐藏时不跟随；移出页面复位

### 4.3 编辑态（设置页「触摸部位」）

- 触摸部位分组「预览 box（在角色上显示）」开关 → 宠物进入**预览态**：强制可见（即使开关为隐藏，退出后恢复）、叠加显示当前草稿的所有 box（部位名标签 + 不同颜色；当前展开部位高亮）；预览只影响显示，不影响编辑与保存；**预览态下点击角色可用草稿 box 正常触发部位台词/动作**（便于边调边试）
- 部位编辑操作：
  - **新建部位**：输入部位名称（最多 24 字）；新部位初始无 box，可继续添加
  - **添加 box**：输入 `左 / 上 / 右 / 下` 四个值，单位为**模型包围盒百分比（0–100，整数）**，存储时除以 100；box 随输入**实时显示在角色上**（无需保存）
  - **一个部位可对应多个 box**；可删除单个 box、删除整个部位
  - **台词**：每个部位可填自定义台词（多行，一行一条；留空 = 该部位只播动作、不出气泡）
  - **动作组**：部位建立后，可为该部位选择当前模型 `.model3.json` 的动作组——与事件绑定卡片同款**多选下拉**（label 也统一为「动作组」；不选 = 只出气泡；多选 = 触摸时随机播一个）
  - **图层排序**：部位卡片带「↑ 上移 / ↓ 下移」与层号（#1 顶层…），列表从上到下 = 顶层到底层；新建部位插入最上层
  - **状态动画映射（当前模型）**：6 个状态槽位各可多选动作组（含内置「简」），保存为该模型的状态动画覆盖层；未配置的槽位沿用内置默认
- 任何草稿变更即时反映到宠物叠加层（预览开启时，未保存也实时）；改动按**部位粒度**标记未保存（卡片顶部「保存」按钮），点保存写回 `$DSH_HOME/waifu/touch-parts.jsonc`（或切换模型/离开设置时自动补存）；保存成功后短暂显示「已保存 HH:MM:SS」
- 关闭预览后宠物恢复常规显示；当前模型切换时自动退出预览并载入新模型的部位（未保存改动先自动补存）
- 用户未保存过部位时，使用内置默认部位（「简」：脸/头发/胸/臀/腰/大腿/手/小腿/脚 九个部位，每个都带示例台词，见 presets.jsonc；默认不挂动作）；保存后以用户文件为准
- 部位数据（含「保存过」状态）经 SSE 随快照下发，宠物即时使用新部位判定

## 5. 任务完成庆祝

- 触发：思考中 → 空闲的下降沿（一轮工作结束）
- 表现：`Done` 动画 + "搞定！"气泡，约 3.5s 后回空闲
- **交付庆祝（ADR-012）**：模型经 present 工具显式交付文件时进入交付态——交付动画（独立槽位，缺省与完成同链）+ delivered 气泡，约 3.5s 后回空闲；交付保持期内紧随的轮次结束（完成）与空闲不打断庆祝；思考/出错/等审批等真实工作流事件仍即时打断；完成保持期内发生交付则升级为交付庆祝
- 当前版本不含音效

## 6. 模型清单与加载

- **本版只内置「简」**（`presets.jsonc` 唯一一条，`modelUrl: /waifu-assets/models/jian/简.model3.json`）；不提供模型选择/导入 UI（自定义模型能力暂不对用户暴露，后续版本再考虑）：
  - 模型资源**随包分发**在 `assets/models/jian/`（moc3、纹理、physics3、cdi3、model3.json、motions）
  - 动作组只有自建 **`Idle`**（循环呼吸/微摆/眨眼，由 `scripts/gen-jian-motions.mjs` 幂等生成）；`model3.json` 声明 `EyeBlink`（ParamEyeLOpen/ROpen）与 `LipSync`（ParamMouthOpenY）参数组
  - 默认事件动画映射：`idle → Idle`，其余事件默认不播动作（只出气泡）；默认触摸部位不挂动作。用户可在设置页用 `Idle` 自行映射
  - 许可标注：作者「用户自备模型」、许可类型「用户自备模型（随包内置；公开分发前请确认模型授权）」
- 素材经 Host 同源 `/waifu-assets/*` prefix 路由提供（带目录穿越防护；moc3/json/png 等 MIME 正确）
- 动作组选项来自当前模型 `.model3.json` 的 `Motions`（设置页事件绑定与触摸部位共用同款多选下拉），解析失败时可保存但无动作可选
- 旧配置里失效的内置模型 id（如 `hiyori`）自动回退到「简」，升级不出现空白
- **加载失败兜底**：显示静态头像占位 + 错误气泡提示，不影响 GUI 其它功能

## 7. 性能与不打扰

- 渲染清晰度：按设备像素比（上限 2x）放大渲染缓冲 + antialias，避免 Retina 上 1x 缓冲放大产生锯齿；触摸部位叠加层同倍率缩放绘制
- 显示区域留白：画布在模型显示尺寸外加留白（设置项「画布留白」水平/垂直，默认 125%/50% of size），避免大幅动作/物理甩尾（如尾巴）在边缘被裁切；「尺寸」仍指模型可见宽度
- 标签页隐藏 / 窗口失焦：暂停渲染循环（保留最后画面），恢复时继续
- 渲染帧率由 `maxFps` 控制（默认 30；可选 60 / 0=不限制）；尺寸变更经 rAF 合并落地
- WebGL 不可用或 FPS 持续过低：自动降级为静态头像模式
- 一键隐藏后完全不渲染（零开销）；隐藏状态持久化；默认小尺寸、右下角，不遮挡主操作区

## 8. 验收要点

- [ ] 插件安装后宠物出现在右下角，加载「简」并播放 Idle（呼吸/微摆/眨眼）；拖动后位置持久化（刷新保持）
- [ ] 拖动与点击互不误触（6px 阈值）；连点立刻换台词并重播动作（80ms 防抖）
- [ ] agent 思考/空闲/出错/完成/交付时，动画与气泡一致（真实事件触发验证）；长思考/等审批气泡按阶段演进
- [ ] 触摸默认部位（脸/头发/胸/臀/腰/大腿/手/小腿/脚）各自触发对应台词（默认不挂动作）；未命中 box 不响应
- [ ] 设置 →「触摸部位」→ 编辑：宠物进入编辑态并显示 box；新建部位、输入名称、添加 box、按**左下角原点**输入左/上/右/下百分比（「上」调大 = box 往上长），box **实时**显示在角色上；一个部位多个 box；退出编辑恢复
- [ ] 新建部位后，该部位的「动画映射」选项出现并可勾选模型动作组；保存后触摸该部位播放所选动作
- [ ] 触摸部位重启/刷新后保持；换模型后部位随之切换；无默认部位的模型点击不响应
- [ ] 「显示触摸部位色块」开发者选项可独立开关叠加层
- [ ] 鼠标跟随（移动/拖拽/移出/隐藏）；完成庆祝与交付庆祝；标签页隐藏暂停；WebGL 不可用降级静态头像
- [ ] 设置面板：开关/尺寸/帧率/模型列表/事件绑定/触摸部位/调试模式生效并持久化（设置写 `$DSH_HOME/waifu/settings.jsonc`；事件绑定与触摸部位写 `$DSH_HOME/waifu/touch-parts.jsonc`；刷新后保持）
- [ ] 事件绑定：6 事件的动作组与台词可改并即时生效；长状态三阶段台词按时间推进；「恢复默认」可用
- [ ] 本版不显示模型选择/导入入口；固定加载内置「简」；加载失败显示静态头像
- [ ] debug 开关：显示调试面板、「演示状态」可强制状态、动画预览可播放模型原生动作

## 9. 技术边界（实现约定，非用户行为）

- 渲染：pixi-live2d-display 0.4.0 + PixiJS 6.5.10 + Cubism Core 4（ADR-003）
- 挂载：Client Slot `shell.overlay`；设置入口：Client Slot `settings.section`（ADR-002）
- 设置：插件私有 `$DSH_HOME/waifu/settings.jsonc`（ADR-013；DSH 0.2.x `ctx.settings` 不再是 namespace 注册表，写入会触发整插件重载；`settings.configure({auto:false})` 隐藏自动表单页）；读写经 `/api/dsh-waifu/settings`（GET `{value,error,path,writable}` / POST `{ops}`）
- 状态源：Host 订阅 `agent/status`、`agent/error`、`agent/turn-stopping`、`approval/request`（ADR-002）；交付态订阅 `session/event` 的 `deliverables/presented`（ADR-012）
- 状态传输：Host→Client 同源 SSE `/api/dsh-waifu/events`（快照 + 变更推送 + 30s 心跳，ADR-006）；首帧走 `GET /api/dsh-waifu/state`
- **事件绑定**（ADR-015）：`EventBindings`（`models.ts`）随 `PetStateView.config.events` 下发；默认台词常量 `DEFAULT_EVENT_BINDINGS` + 模型 `animationMap` 提供动作组，用户覆盖存 `touch-parts.jsonc` 的 `models[<id>].events`（整事件替换）；无固定人设，后续 LLM 人设走提示词
- **模型与素材**：内置模型随包（`assets/models/jian/`），`/waifu-assets/*` prefix 路由（目录穿越防护）；本版 UI 不暴露模型选择/自定义模型
- **触摸部位**（ADR-014）：`TouchPart`/`TouchBox` 共享类型与纯函数（`normalizeTouchParts` / `pointToBoundsRatio` / `hitTestTouchParts`）在 `src/models.ts`；Host `TouchPartsStore` 读写 `$DSH_HOME/waifu/touch-parts.jsonc`（按模型 id 分组：`parts` + 可选 `animationMap` 覆盖层；未保存回退内置默认）；client 设置页与宠物层通过 `window` CustomEvent（`dsh-waifu:touch-edit`）传递编辑态与草稿部位；宠物层用 `model.getBounds()` 换算 box 到画布坐标绘制叠加层
- 动作管理：pixi-live2d-display `MotionPriority`（IDLE=1 / NORMAL=2 / FORCE=3），idle 用 IDLE、状态与互动用 FORCE；重播同一动作前先 `stopAllMotions()`；完成信号统一用 `motionFinish`（ADR-008）
- focus 抑制：非 idle 动作播放期间 `focusController.focus(0, 0, true)` 归零 + `pointermove` 门控，`motionFinish` 后恢复（ADR-008）
- 动画映射：`resolveMotionMap()` 合并 `DEFAULT_MOTION_MAP` + 自定义条目/内置 preset；状态槽位 6 个；部位动作走 `part.motions`（ADR-014）
- 自建动作：`scripts/gen-jian-motions.mjs`（纯 Node，无三方依赖）幂等生成 motion3.json，自动计算 Meta 计数并校验参数 ID 存在于 `简.cdi3.json`

## 10. 明确不做

- 多内置模型清单（当前只有「简」）
- 动作可视化编辑器（动作由脚本生成）
- 曲线/多边形触摸区域（只有矩形 box，多 box 近似）
- 喂食/养成玩法、通知中心替代、音效、模型市场
- LLM 人设提示词说话（后续版本）；人设随机切换/混合人格；`fs.watch` 热重载
- 重置位置按钮、隐藏快捷键、可配置停靠角（固定右下角）、尺寸三档（连续滑杆）
- 自定义模型导入/选择（本版只专注内置「简」）
