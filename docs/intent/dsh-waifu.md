# Intent: Live2D 宠物插件

Confirmed intent（已经用户确认的方向）。

## Outcome

为 DSH Web GUI 提供一款**实用陪伴型** Live2D 桌宠插件：宠物成为 Agent 状态镜像（思考 / 工作 / 空闲 / 出错动画与气泡）+ 互动陪伴（**用户自定义触摸部位**（touchbox）/ **鼠标跟随**（头/眼/身体看向鼠标）/ 任务完成庆祝）。

**事件绑定（2026-11 取代固定人设）**：台词与动画按**事件**配置——空闲 / 思考中 / 出错 / 完成 / 交付 / 等审批；每个事件可配动作组候选 + 台词池（长状态三阶段），设置页单页直接编辑、可恢复默认。**固定六人设体系已彻底移除**（原 personaje JSONC 文件入口、人设切换、`reload-personas` 全部删除）；后续版本计划加入 **LLM 人设提示词说话**（以事件绑定为落点，不改事件/动作结构）。

**模型策略（2026-11 调整为随包内置）**：内置模型收敛为**唯一一个「简」**（用户自备的 VTube Studio 半身像模型），随插件包分发（moc3/纹理/物理/cdi3 + 插件自建动作），开箱即可用；配套提供 `scripts/gen-jian-motions.mjs` 幂等生成状态动作与触摸动作。**本版设置页不提供模型选择/导入，只专注这一个内置模型**。

**触摸部位（2026-11 重做）**：不再固定「头/腿/手/身体」四档，也不依赖模型 HitArea；部位抽象为**用户自定义 touchbox**：每个部位有名字 + 一到多个矩形 box + 该部位的触摸动作组。设置页「触摸部位」提供：编辑开关（模型进入编辑态、box 实时显示在角色上）、新建部位、添加 box、输入左上右下百分比、一个部位多个 box、按部位多选触摸动画。

内置 DSH 设置面板「桌宠配置」tab（`settings.section`），单页设置项：**开关 / 尺寸滑杆 / 渲染帧率 / 画布留白 / 默认位置与归位 / 对白气泡 / 事件绑定 / 触摸部位 / 开发者选项**；标量配置持久化于插件私有 `$DSH_HOME/waifu/settings.jsonc`（DSH 0.2.x settings 服务适配，ADR-013）；事件绑定与触摸部位走 `$DSH_HOME/waifu/touch-parts.jsonc`（ADR-014/015）。

## User

- DSH 重度用户（开发者）：长任务等待期的陪伴与状态感知
- DSH 潜在新用户：作为产品差异化与情感化卖点吸引

## Why now

- DSH 需要从"纯工具"走向"有性格的工具"，桌宠是低成本高感知的差异化
- Agent 长任务执行期的等待是真实 UX 空白，宠物可同时承担状态可视化
- Live2D Web 技术栈成熟（Cubism Web SDK / pixi-live2d-display），浏览器内可运行
- 用户提供了自备的高质量 Live2D 模型（「简」），并希望部位互动完全可按自己的模型比例配置
- 中文开发者社区对桌宠/看板娘文化接受度高（live2d-widget 等先例）

## Success

1. 插件可安装到 DSH Web GUI，宠物正常渲染、交互、不干扰工作
2. 状态镜像准确：思考 / 工作 / 空闲 / 出错动画与气泡与 agent 状态一致（「简」的动作组由插件自建）
3. 互动可玩：触摸用户自定义部位各有专属反应；鼠标在页面移动时头/眼/身体平滑跟随；任务完成有庆祝反馈
4. 事件绑定成立：6 个事件的动作与台词可在设置页修改并即时生效；长状态三阶段台词按时间推进；没有固定人设，后续由 LLM 人设提示词接管说话
5. 设置可达：设置面板「桌宠配置」tab 各项设置生效并持久化（无模型选择/导入入口）
6. 触摸部位可自由定义：编辑态实时显示 box；新建部位/多 box/百分比输入/按部位动画映射全流程可用并持久化
7. 模型清单条目**许可可标注**（每条记录许可类型与链接）；内置「简」为随包分发模型并明确标注授权提示
8. 留存指标：重度用户持续启用（启用时长 / 关闭原因可观测）

## Constraint

- **许可合规**：模型清单条目只需**许可可标注**——记录许可类型与链接即可收录，不做许可合规判断；NC（禁止商用）模型可标注"仅限非商用"；内置「简」明确标注为「用户自备模型（随包内置；公开分发前请确认模型授权）」；SDK 遵守官方条款（版权声明）；代码库避开 GPL 传染
- 性能：标签页隐藏时暂停渲染；低配机器回退静态头像
- 不打扰：小尺寸、默认右下角停靠、可拖动、可隐藏、可关闭
- 技术栈：Cordis 插件（Client 渲染 + Host 资产管理/状态事件），WebGL，DSH Web GUI Slot 注册
- 兼容：适配当前 DSH Desktop 0.2.x（settings 服务语义变化，ADR-013）

## Out of scope

- 完整通用 Live2D 运行时（任意模型全特性兼容）——本版只支持内置「简」
- 多内置模型策展清单（当前收敛为「简」一个；未来如需再扩充）
- 动作编辑器的可视化编辑（自建动作以脚本 + motion3.json 维护，不做 GUI 关键帧编辑器）
- 通知中心替代——后续增值，非当前范围
- 脱离页面的桌面宠物 / 独立窗口
- 自研建模与美术（模型依赖用户自备/第三方）
- 设置面板范围外配置：可配置停靠角（默认固定在右下角，支持拖动与默认位置）、隐藏快捷键、尺寸三档（用连续滑杆）
- LLM 人设提示词说话（后续版本）；人设随机切换/混合人格；文件监听热重载
- 触摸部位的曲线/多边形等复杂几何（只用矩形 box，多个 box 组合近似）
- 自定义模型导入/选择（本版只专注内置「简」，后续版本再考虑）
